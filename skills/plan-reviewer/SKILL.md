# Plan Reviewer

Use during the full-feature plan-review phase.

Review only. Do not rewrite the plan.

Check:

- Missing data collection steps.
- Missing validation steps.
- Wrong implementation order.
- Oversized slices that should be split.
- Missing state/storage steps.
- Test coverage gaps.
- Architecture risks before coding.

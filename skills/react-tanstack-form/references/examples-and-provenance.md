# Examples and Provenance

## Evidence Boundary

Sources were researched on **2026-09-16**. This is a retrieval date, not a rule's effective date or proof of runtime behavior. API statements below are source-backed; draft/result ownership, accessibility completion, and server trust guidance are this skill's engineering judgments. Examples are learning material, not audited production templates.

| Evidence | Reference point | How to use it |

Research observed npm `latest` as 1.33.5 and `alpha` as 2.0.0-alpha.2. These are historical observations, not installation instructions. Resolve the application's actual lockfile and package exports. For a newer major, retain general state/trust principles but consult its matching documentation before using any v1-specific snippet.

For community comparison, [felipestanzani/shadcn-tanstack-form](https://github.com/felipestanzani/shadcn-tanstack-form/tree/efb26f120fa17362d4ef5f792e22b1af681eb000) has useful `useId` and error-visibility adapters, with researched lock resolutions Form 1.14.1 and Zod 4.0.5. Its older `useStore` style is not itself a bug; review first-error-only rendering and description IDs. The [MIT license](https://github.com/felipestanzani/shadcn-tanstack-form/blob/efb26f120fa17362d4ef5f792e22b1af681eb000/LICENSE) was found in the source survey.

[ysmello/tanstack-form-stepper](https://github.com/ysmello/tanstack-form-stepper/tree/ed4816a4650cb0384868551c5a83413e92a4aee4) illustrates `withFieldGroup` and step-specific schemas with researched Form 1.19.5. It is a comparison case, not the preferred wizard template: a cast to the complete schema type does not execute complete-schema validation. No reuse license was established in that surveyed revision; analyze its ideas without copying its code unless permission is obtained.

The first supported version of every newer v1 export, all adapter cookie security properties, and every framework/example combination were not established. The later main SSR page linked a Start workflow guide that was unavailable during research; no claims here depend on that missing guide. Installed declarations, matching source, and an exercised application path take priority over extrapolation from these examples.

# 과거 버그 PR·이슈와 회귀 금지 조건 원장

- 회귀 금지 조건의 갱신 정본은 이 파일이다. 사용 절차는 [개발 검증 기준](../verification-policy.md#회귀-대조)을 따른다.
- 초기 자료는 2026-10-09에 PR #1–#291과 당시 이슈를 분류한 결과다. 이후 merge된 PR은 아래 "원장 작성 뒤 merge된 PR"에 추가한다.
- [bug-ledger.json](bug-ledger.json)은 초기 173건의 증상·원인·수정을 담은 2026-10-09 고정 원자료다. JSON은 갱신하지 않는다. 내부 `/tmp` 출처는 당시 조사 기록이며 실행에 필요한 경로가 아니다.
- guard는 항목 작성 시점의 회귀 테스트다. node id의 존재나 기록만으로 통과를 뜻하지 않는다. 변경 전에 실제 테스트와 해당 조건의 검증 범위를 확인한다.
- 본문의 state, HEAD, "현재", 파일 줄 번호는 각 항목을 작성한 당시의 기록이다. 대체·역전된 계약과 알려진 빈틈을 함께 읽는다.
- 사용자 소유 raw 사본은 보존 자료다. 새 항목과 확인 결과는 이 정본에만 반영한다.

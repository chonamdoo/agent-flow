## Context (our system, for comparison only)
Agent Flow is an open-source kit that forces AI coding agents (Claude Code, Codex CLI, OMP) through a fixed workflow. A Python runner is the sole authority for phase order and routing; workflows such as `full-feature`, `development`, `bugfix`, `review` are defined in YAML files (phases, routes on verdicts, required artifacts/markers, multi_review flags, fix-loop caps). The runner pins the YAML content into each run's record at start and validates on resume. Host hooks (pre/post tool use) call the same Python for write-boundary protection. Question from the owner: is YAML a real advantage, and what do comparable projects use?

# Installable workflow kit

## What to build

Make Agent Flow easy to clone or copy into other projects as a reusable Workflow Kit rather than an app.

## Acceptance criteria

- [ ] README documents the install/copy path for a new project.
- [ ] Packaged resources include workflows, profiles, roles, and templates.
- [ ] A smoke test verifies the installed CLI can initialize and start a run from outside the source tree.

## Blocked by

- Host provider discovery.

# Research Context

Use only for research, product-brief, PRD, or issue-discovery phases.

## Load With

- `CONTEXT.md`
- Relevant user brief, issue, PRD, or observed behavior notes
- Only the source material needed for the active question

## Keep Out

- Full raw transcripts
- Long copied articles
- Broad competitor dumps without task relevance
- Local absolute paths

## Artifact Shape

- Question
- Sources checked
- Evidence summary
- Decision impact
- Open risks
- Next phase input

# Paper Runtime Context

Use only when a phase needs technical paper/spec/runtime details.

## Load With

- `CONTEXT.md`
- The specific paper/spec section needed for the phase
- Changed files or target modules, not the whole repo

## Rules

- Prefer short extracted claims with source references.
- Do not paste full papers into artifacts.
- Keep implementation guidance tied to current code paths.
- Record uncertainty and assumptions explicitly.

## Artifact Shape

- Claim
- Source section
- Code impact
- Test/gate impact
- Deferred reading

# Task: global beauty commerce site (goal-only layer, v1)

Build a global beauty commerce site: a web frontend and its backend. Shoppers anywhere can search and browse the
catalog, open a product, put it in a cart, and see what shipping to their country costs in their currency.

Use `fixtures/catalog.json` and `fixtures/commerce.json` as the only data (`commerce.json` wins where they overlap). Follow `contract/interface.md` (how the
build is started, routes, test ids) and `contract/openapi.yaml` (the API). Everything else is your call.
